# 민수와 주방장 1 : 해병 짜장 만들기

실행: 세 파일(index.html, style.css, script.js)을 같은 폴더에 두고 index.html을 열면 됩니다. 정적 호스팅(GitHub Pages, Netlify 등)에 그대로 올릴 수 있습니다.

조작: 재료를 끌어다 놓기 / 요리시작·꺼내기(스페이스바) / 일시정지(P, Esc)

## 판매·배포 전 확인
- 폰트: Jua(Google Fonts, SIL OFL)를 온라인으로 불러옵니다. 오프라인 배포 시 폰트 파일을 직접 포함하세요.
- 그래픽: 캐릭터는 SVG, 재료·아이콘은 기기 이모지입니다. 기기마다 모양이 달라지므로, 상용 배포라면 전용 일러스트로 교체하길 권합니다.
- 소리: 효과음·BGM은 코드로 생성, 음성은 기기 TTS를 사용합니다(기기에 따라 없을 수 있음).
- 명칭: '해병' 명칭과 휘장은 공식 기관 관련 이용 규정이 있을 수 있어 상업 배포 전 확인이 필요합니다. 공식 휘장은 사용하지 않았습니다.
- 실제 기기(iOS/Android/PC)에서의 플레이 테스트는 별도로 진행하세요.
