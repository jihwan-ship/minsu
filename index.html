민수와 주방장 1

해병 짜장 만들기

황근출 해병님이 지켜보고 있다!
⚠ 레시피를 3번 틀리면 배드 엔딩!
정확할수록 점수↑, 최종 계급은 이병 → 병장!
재료를 끌어다 냄비·팬·그릇에 놓고, 막대가 잘익힘일 때 꺼내세요.

볶은야채돼지고기

식용유 + 야채 + 돼지고기 → 팬 → 요리시작 → 잘익힘에서 꺼내기

볶은춘장

춘장 → 팬 → 요리시작 → 잘익힘에서 꺼내기

짜장

볶은야채 + 볶은춘장 + 마늘 + 설탕 + 식용유 + 물 → 팬 → 요리시작

삶은면

물 + 생면 → 냄비 → 요리시작 → 잘익힘에서 꺼내기

완성

짜장 + 삶은면 → 그릇 → 완성 버튼

잘못 넣었다면 냄비·팬·그릇을 클릭하면 비워져요.

⚠ 틀린 레시피로 요리시작을 3번 누르면 배드 엔딩!
